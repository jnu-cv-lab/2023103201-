
# DFT 与 DCT 的关系及其在图像处理中的边界条件解释

## 作业目标
通过公式分析、边界延拓理解和简单实验，对比离散傅里叶变换（DFT）与离散余弦变换（DCT）的关系，理解它们各自隐含的边界条件假设，并分析为什么在图像压缩和图像处理任务中 DCT 往往比 DFT 更常用。

## 1. 数学定义与基础问题
分别写出一维 DFT 和一维 DCT（建议采用 DCT-II）的数学定义，并说明：
- 两者的基函数分别是什么
- 两者输出系数的主要形式有何不同
- DCT 与 DFT 在 “频域分解” 思想上有什么共同点

## 2. DFT 与 DCT 的关系
从 “信号展开” 的角度说明 DCT 与 DFT 的关系。要求回答：
- DCT 是否可以看作某种特殊条件下的傅里叶分析
- DCT 与偶对称延拓有什么关系
- 为什么 DCT 中只出现余弦项，而没有正弦项或显式虚部

选取一个长度较短的一维信号，或者一幅灰度图中的一行像素作为测试对象。

## 4. 延拓方式对比
对同一个序列，分别构造：
- 按 DFT 隐含假设得到的周期延拓示意
- 按 DCT 隐含假设得到的偶对称延拓示意

要求画图并列出扩展后的序列，并说明两者在边界处的差异。

## 5. 频谱对比
分别计算该序列的 DFT 和 DCT 系数，并回答：
- 哪一种变换下，能量更集中在低频部分
- 原因是什么

提示：可以用 “前若干个系数所占能量比例” 作为比较指标。
