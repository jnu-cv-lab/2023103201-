# 实验七：传统机器学习方法用于图像分类

## 📌 作业题目
传统机器学习方法在手写数字图像分类中的应用

---

## 🎯 作业目标
通过本次作业，你将掌握：
1.  图像如何转换为机器学习模型可处理的特征向量
2.  训练集与测试集的划分与基本概念
3.  常见传统机器学习分类方法的基本使用
4.  不同分类器在同一图像分类任务中的表现差异
5.  如何使用**准确率、混淆矩阵、错误样本分析**评价分类结果

---

## 📊 数据集要求
本次作业使用 `scikit-learn` 自带的 `digits` 手写数字数据集。

### 数据集基本信息
| 项目 | 内容 |
| :--- | :--- |
| 数据类型 | 手写数字灰度图像 |
| 图像大小 | 8 × 8 |
| 类别数量 | 10 类 |
| 类别标签 | 0 ~ 9 |
| 任务类型 | 图像分类 |

> 每张 8×8 图像可展开为一个 **64 维特征向量**，直接用于训练机器学习分类器。
