# 图像缩小、恢复与频域分析实验
基于 OpenCV 的图像下采样、插值恢复与频域分析实验

## 实验内容
1. 图像读入与预处理
2. 图像下采样（1/2 或 1/4）
   - 不做预滤波直接缩小
   - 先高斯平滑再缩小（抗混叠）
3. 图像恢复（三种插值方法）
   - 最近邻内插
   - 双线性内插
   - 双三次内插
4. 空间域比较
   - 显示原图、缩小图、恢复图
   - 计算 MSE
   - 计算 PSNR
5. 傅里叶变换分析
   - 对原图、缩小图、双线性恢复图计算二维傅里叶变换
   - 将频谱中心移到图像中心
   - 对幅度谱取对数显示
   - 比较高频成分差异并说明原因
6. DCT 分析
   - 对原图和恢复图像做二维 DCT
   - 显示 DCT 系数图
   - 统计左上角低频区域能量占比
   - 比较不同恢复方法的 DCT 能量分布差异并解释
