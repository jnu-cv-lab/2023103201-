## 实验主题：基于 OpenCV 的局部特征检测、描述与图像匹配
用box.png 和 box_in_scene.png
## 实验内容
### 任务1：ORB 特征检测
调用 ORB 算法提取模板图与场景图的关键点及特征描述子，并可视化关键点分布。实验观察发现：特征点主要集中在角点、边缘、文字与纹理丰富区域，平坦纯色区域几乎不存在特征点，以此理解关键点分布规律与实际作用。

### 任务2：ORB 特征粗匹配
采用暴力匹配结合汉明距离完成特征初步配对，按匹配距离升序排序，分别保存前30、前50组匹配结果。仅依靠描述子相似度进行匹配时，受相似纹理、复杂背景干扰影响，存在大量误匹配，匹配连线杂乱无序，匹配可靠性较差。

### 任务3：RANSAC 剔除误匹配
利用匹配点对求解单应矩阵，结合 RANSAC 算法依据几何一致性约束筛选内点、剔除误匹配外点。经过滤后，保留符合透视变换关系的有效匹配对，显著减少错误匹配，提升匹配整体合理性，为后续目标定位提供稳定可靠的基础数据。

### 任务4：平面目标定位
利用求解得到的单应矩阵，将模板图像四个角点进行透视变换并映射至场景图像，绘制红色闭合包围框标记目标区域，完成平面目标的精准检测与定位可视化。

### 任务6：ORB 参数对比实验
控制单一变量，修改 ORB 算子的 nfeatures 参数，分别测试 500、1000、2000 三组配置。实验表明：特征点数量增加会提升总匹配数量，但过量冗余特征会降低有效内点占比，易造成目标定位偏移、检测边框溢出；证明特征点数量并非越多越好，需合理选取参数。

### 选做：ORB 与 SIFT 算法对比
实现 SIFT 特征检测、KNN 双向匹配与 Lowe 比例约束筛选。两种算法差异明显：ORB 为二进制描述子，运算速度快、模型轻量化，适合实时场景；SIFT 基于浮点梯度特征，抗干扰与鲁棒性更强，但计算开销大、耗时更长，适用于高精度要求的视觉任务。
