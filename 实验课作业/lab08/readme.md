
# 实验 8：PyTorch 入门与图像分类

## 一、实验目的
本实验使用 PyTorch 完成一个简单的图像分类任务，完整体验深度学习图像分类的基本流程：
`数据加载 → 模型定义 → 训练 → 验证 → 测试 → 结果分析`

通过本次实验，掌握图像分类任务的核心组成部分，并能独立运行一个基于 CNN 的图像分类实验。

---

## 二、基础实验任务完成情况

### 任务 1：环境准备
- 安装并测试 PyTorch、torchvision、NumPy、Matplotlib 等依赖库
- 成功导入 PyTorch 并验证版本
- 判断当前环境是否支持 GPU
- 运行基础 PyTorch 张量操作，验证环境配置正常

### 任务 2：加载图像数据集
- 使用 MNIST 手写数字数据集完成图像分类实验
- 加载训练集与测试集
- 将训练集按比例划分为训练子集与验证子集
- 显示至少 8 张样本图像，并标注真实类别

### 任务 3：定义 CNN 模型
- 设计包含卷积层、激活函数、池化层、全连接层的卷积神经网络
- 模型输入尺寸匹配数据集图像尺寸
- 模型输出类别数与数据集类别数一致
- 在实验报告中记录完整模型结构

### 任务 4：模型训练
- 使用训练集训练 CNN 模型
- 选择合适的损失函数与优化器
- 训练轮数不少于 5 个 epoch
- 每个 epoch 记录训练 loss 与训练 accuracy

### 任务 5：模型验证
- 每个 epoch 结束后在验证集上评估模型
- 记录验证 loss 与验证 accuracy
- 对比训练集与验证集的表现差异

### 任务 6：模型测试
- 训练完成后，使用测试集评估最终模型性能
- 输出测试集 loss 与测试集 accuracy
- 显示至少 8 张测试图像，并标注真实类别与模型预测类别

### 任务 7：绘制训练曲线
- 绘制训练 loss 与验证 loss 曲线
- 绘制训练 accuracy 与验证 accuracy 曲线
- 横轴为 epoch，纵轴为 loss/accuracy，包含标题、坐标轴标签与图例

### 任务 8：实验结果分析
- 分析训练 loss 随 epoch 的变化趋势
- 分析验证 accuracy 的变化情况
- 对比训练 accuracy 与验证 accuracy 的差距，判断是否过拟合
- 分析易混淆的数字/类别
- 比较 MNIST 与 CIFAR-10 的分类难度并解释原因
